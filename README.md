# Python Basics

Beginner-friendly Python scripts that I wrote while learning the fundamentals of the language. Each file focuses on one topic, so it can be read and run on its own.

## What's inside

| File | Topic |
|------|-------|
| `variables.py` | Variables that store personal information |
| `data_types.py` | Basic data type examples |
| `strings.py` | String operations |
| `lists.py` | Basic operations on a student list |
| `if_else.py` | An if-else program that determines grades |
| `loops.py` | Loops using `for` and `while` |
| `functions.py` | Functions for addition and multiplication |

## How to run

You need Python 3 installed.

```bash
git clone https://github.com/SudhakshinaV/Python-Basics.git
cd Python-Basics
python loops.py
```

Replace `loops.py` with any file from the table.
